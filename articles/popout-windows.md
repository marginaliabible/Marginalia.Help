# Popout Windows

The Popout Windows feature is a great way to study if you have a large screen or multiple monitors. It is a desktop-only feature that lets you open the [document viewer](document-viewer) and/or the side panels (such as the [Resources](resources) or [Translations](translations) panels) in separate browser windows.

These can be opened by clicking the <i class="fa-solid fa-up-right-from-square" aria-hidden="true"></i> button in the top-right corner of the document viewer or side panel.

The first time you open a popout window you will be prompted to allow Marginalia to manage windows. Allowing this will let the app remember the last position and size of its windows and help Marginalia ensure windows are brought back to the foreground when they are reused.

Once a window is popped out, other windows from Marginalia will interact with that window. For example, if you are viewing a document in a popped out [document viewer](document-viewer) and select a resource in the [Resources](resources) panel, the resource will open in the popped out document viewer window. Similarly, if you select a Bible verse in your main window and the side panels are popped out, the corresponding translation will open in the popped out [Translations](translations) panel. When this cross-window interaction happens, a toast notification will be displayed in the main window to let you know. Clicking "Got it!" will dismiss the notification and temporarily prevent it from being displayed.
