# Resources Panel

Marginalia indexes all of your resources by scripture reference then makes them available for each verse. Resources can include your own notes synced from your cloud provider and resources from your ministry, all of which are configured via [Account Sync](account-sync). You can then access those resources via the Resources side panel.

[Show me how](tour:resources-panel)

The colorful circles around the verse numbers in your Bible indicate that resources are available for that verse. Multiple colors indicate there are different tagged resources available. Up to five colors will be displayed for a verse. If more than five different tags apply, a **+** symbol is also displayed. Clicking a verse number opens the Resources side panel for that verse.

The top of the panel displays the currently selected verse or verses. Clicking the verse reference jumps to the first selected verse in your Bible. If multiple verses are selected, an `ALL` | `ANY` toggle lets filter to resources containing  *all* the selected verses or *any* of them.

## Resource Tags

When selecting resources from the [Account Sync](account-sync) panel, you can tag resources, each tag being assigned a unique color. The tags for the currently selected verse or verses are displayed at the top of the Resources panel. Clicking a tag toggles the display of resources with that tag. Toggling persists for your current session, and is reflected in the colors of the circles around the verse numbers in your Bible. This allows you to browse only the resources you're interested in for your current study session.

Below the tags are the resources for the currently selected verse(s)/tags. Each verse has a swatch with the color for each tag for that resource. You can view the resource name by hovering over the swatch (desktop) or long-pressing it (mobile).

## Resource Cards

Each resource is displayed as a card with the resource's name, a swatch for each tag, the page number(s) the selected verse(s) appear on in that resource. Clicking a page number opens the resource to that page in the [document viewer](document-viewer), highlighting the verse in the document.
